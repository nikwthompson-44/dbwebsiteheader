How to Use

  1. Export the GIF: Click "Record GIF" above. The animation will play through one full cycle, then the GIF downloads automatically.
  2. Host the GIF: Upload the exported .gif file to your image hosting (e.g., your CMS, S3 bucket, or the same host as your other email assets).
  3. Update the HTML: In the HTML snippet above, replace YOUR_GIF_URL_HERE with the public URL of the hosted GIF.
  4. Add to Salesforce: Go to Setup → Email → My Email Settings (or Organization-Wide Email Signatures). Paste the HTML snippet into the signature editor (switch to HTML/source mode).
  5. Salesforce merge fields: The name uses {!$User.FirstName} {!$User.LastName} so each user sees their own name. The phone is hardcoded to 08 6208 6699.
  6. Test: Send a test email to Gmail, Outlook, and Apple Mail to verify. Outlook desktop may show only the first GIF frame (static), while other clients will animate.
